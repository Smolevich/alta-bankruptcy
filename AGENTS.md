# alta-bankruptcy

Reference site for depositors of the Serbian bank ALTA, focused on amounts above EUR 50,000.
Astro + Starlight in `src/`, three languages: ru (root, default), en (`/en/`), sr (`/sr/`, Latin).
`backend/` is the Python service that serves the whole site; see `backend/AGENTS.md`.

```bash
npm ci
npm run dev                        # http://localhost:4321
npm run check                      # check:i18n + build (frontmatter schema, internal links)
npm run check:sources [-- --dist]  # external links against the trusted-domain registry
npm run test:scripts               # node --test scripts/*.test.mjs
node scripts/check-anchors.mjs dist
```

Code rules and tests: `docs/coding-standards.md`. Deploy: `docs/deploy.md`. Data the site collects:
`docs/privacy.md`.

## Content

- **No source, no edit.** Every page and news item has `sources` (title, url, kind, date) and
  `checked` in the frontmatter (`src/content.config.ts`). `kind`: `official` (state bodies, courts,
  banks, regulator) | `reference` | `own` | `reliable_media` | `unverified`. A claim without an
  official source is published only with a visible «со слов вкладчика / источника нет» mark;
  guesses and estimates never.
- **Every external source has a backup.** A PDF goes to `public/docs/` and `src/data/pdfs.ts` (the
  build fails on a PDF without one; AOD documents live in `backend/src/alta_feedback/data/aod_archive.json`);
  a web page gets a web.archive.org or archive.ph snapshot in the source's `copy`. A document naming
  private persons is `public: false` and stays an external link. A file with no official original
  (e.g. sent by a depositor) is not published as a document.
- **External links only to trusted domains** from `src/data/trusted-domains.yaml` (`name`, `proof`),
  https only, no shorteners.
- **Three languages move together**: a fact, figure, date or link changed in one language changes in
  the other two in the same PR, or the PR says "translation lags". `check:i18n` checks that pages
  exist and `sources`/external links match. Serbian uses the official terms: stečaj, poverilac,
  prijava potraživanja, isplatni red, Agencija za osiguranje depozita, Narodna banka Srbije,
  Privredni sud u Beogradu.
- **Anchors are short English ASCII**, identical across languages, generated by `src/heading-ids.mjs`
  (the build fails if the heading count differs). Renaming one requires old→new in
  `public/anchor-redirects.json`.
- News: one file per item and language, `src/content/news/<lang>/<date>-<slug>.md`.
- Not on the site: whether the failure was predictable, ownership of media, chats, depositor
  verification, Telegram forms, accusations against people. Bank financial figures only from official
  reports (APR, the bank, NBS, AOD) with the page number and a copy in `public/docs/`; what the
  documents do not disclose is written as «в документах не раскрыто: …». On `/account/stats` the
  collapsed «Со слов вкладчиков в чатах» block lists criteria from open chats without counts, quotes,
  names or chat titles (`backend/src/alta_feedback/data/bank_criteria.json`).
- Sole traders (ИП): short notes only through the `ForIp` component.

## Repository

- **No personal data, history included**: no names, emails, phones, JMBG, account numbers or
  Telegram handles of depositors, chat members or form authors; no unredacted screenshots or
  filled-in forms. The repo is public; a leak means rotating and reporting. Official contacts of
  organisations are fine.
- No secrets or server addresses in the repo. Deploy only through CI; never edit the server by hand.
- Dependency security: Dependabot alerts and security updates, secret scanning with push protection,
  CodeQL (default setup) and private vulnerability reporting are on; CI fails on high/critical npm
  advisories and on any known Python advisory. A security alert is fixed first: merge the Dependabot
  PR once CI is green, or bump the package by hand; a major bump goes through a normal reviewed PR.
- Light theme only. No third-party scripts or fonts; the only external script is Cloudflare Web
  Analytics, allowed by the CSP in `backend/src/alta_feedback/site.py`.
- Everything outside site content and UI strings is in English: docs, code comments, commits, PRs.
- PR description needs `## What`, `## Why`, `## Checks` (`pr-description.yml`). Required checks:
  `build`, `backend`, `pr-description`. Paths in `.github/CODEOWNERS` (`.github/`, `scripts/`,
  `package*.json`, `astro.config.mjs`, `src/data/trusted-domains.yaml`, `backend/deploy/`,
  `backend/pyproject.toml`, `backend/uv.lock`) need a code owner's review. Merge with squash.
