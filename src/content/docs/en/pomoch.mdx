The site is open: the text lives on [GitHub](https://github.com/Smolevich/alta-bankruptcy) and anyone can suggest an edit. There is one main rule: **no source, no edit.**

<h2 id="about">Who makes this site</h2>

The site is made by ALTA depositors. We are not lawyers and not an association. Every statement on the site has a source, listed at the bottom of each page. This site is not legal advice: for your own case, see a lawyer ([how to check a lawyer](/en/bezopasnost/)). To reach us: [open an issue on GitHub](https://github.com/Smolevich/alta-bankruptcy/issues/new).

## The rule

Every figure, deadline and statement on the site has a source. If you know there is a mistake somewhere but have no source, report it in an [issue](https://github.com/Smolevich/alta-bankruptcy/issues/new): the edit will be made once a source appears.

## Levels of source reliability

- **Official source**: a law, an announcement from AOD, the National Bank or a court, a document of the bank itself. Accepted immediately.
- **Reliable media**: a publication that links to a document or gives names and dates. Accepted as supporting detail and marked as such on the page; a primary source is still better.
- **Unverified**: a chat, a rumour, a retelling without a link. It never goes on the site.

## How to correct

**Through the GitHub site.** Every page has an "Edit page" link. A web editor opens; make the edit, add the source to the page header (`sources`) and press "Propose changes". Fill in the template in the description: what changes, the primary source, a link.

A person reviews every edit, and a source is required.

## Three languages

The site is in Russian, English and Serbian. If you fix a fact in one language, fix it in the same PR in the others. If you cannot, add the note "translation lags" to the PR description. The build check makes sure no page goes missing in any language, but it will not translate your edit for you.

## A news item

A news item is one file in `src/content/news/ru/` (and the same in `en/` and `sr/`). Use any neighbouring file as a model: date, publisher (`aod`, `nbs`, `bank`, `court`), a short summary and a link to the announcement. Without a link to the primary source the site will not build.

## Reporting an opened account

This is not a site edit: use the [anonymous form](/account) and the [statistics from the answers](/account/stats).
